# BlackVolt Technologies — website redesign

A static, responsive Vite site for BlackVolt Technologies. It presents VAJRA-KAAL as an indigenous AI-native counter-UAS system concept, separates documented design intent from the current research and prototyping status, and includes an interactive Three.js viewer with original procedural models for the printed interceptor airframe, Sprint and Picket concept roles, and the multirotor EO detection testbed.

## Development

- `pnpm install` installs the pinned dependencies.
- `pnpm dev` serves the site on port 3000.
- `pnpm check` runs TypeScript diagnostics.
- `pnpm build` type-checks and writes the static site to `dist/`.

## Content and asset provenance

Product, maturity and contact claims follow the user-supplied *VAJRA-KAAL System Concept & Architecture*, revision 3.0, August 2026. The maturity snapshot is date-stamped to that source. Current hardware photographs are extracted from its pages 33–34. Three.js meshes are original, programmatically generated illustrations; they are not engineering drawings or depictions of flight-ready products. The previous site's unsupported platform metrics and placeholder imagery are not used.
